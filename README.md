# Sign-Up Page

A modern, responsive sign-up interface built with vanilla JavaScript, HTML, and CSS. This project features an immersive cosmic video background paired with a sleek glassmorphism card, smooth interactive states, and accessible form controls.

## Features

* **Glassmorphism UI:** Frosted glass aesthetic styled using backdrop filters, translucent borders, and soft shadows over an ambient background.
* **Dynamic Video Background:** Seamlessly loops a local cosmos video with accessibility track support (`captions` and `descriptions`).
* **Password Show/Hide Toggle:** Interactive SVG icon toggle allowing users to switch between masked and plain text password visibility.
* **Accessible & Semantic Form:** Built using semantic HTML5 elements, explicit label associations, autocomplete attributes, and clean focus rings.
* **Responsive Layout:** Centered, neatly contained user interface using CSS Flexbox optimized for desktop and mobile viewports.

## Technologies Used

* **HTML5:** Semantic document structure, form inputs, native `<video>` embedding, and accessibility tracks.
* **CSS3:** Flexbox for layout management, glassmorphism (`backdrop-filter`), custom typography (Plus Jakarta Sans via Google Fonts), and smooth micro-interactions.
* **JavaScript (ES6+):** DOM manipulation, event listeners (`click`, `submit`), and dynamic password toggle logic.

## How to Run Locally

Since this is a vanilla front-end project, no build tools or package managers are required.

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/arinskyyyy/sign-up-page.git
   ```

2. Navigate into the project directory:
   ```bash
   cd sign-up-page
   ```

3. Open the `index.html` file in your preferred web browser.
